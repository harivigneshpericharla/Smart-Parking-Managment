DSA Engine Room

The data structures & algorithms running under the hood.

Queue — FIFO Slot Allocation

Free slots wait in a queue; the vehicle at the front of the arrival line gets the slot at the front of the queue.

HashMap — Instant Vehicle Search

Registration numbers hash to buckets, giving O(1) average lookup time.

Linked List — Parking History

Each visit is a node linked to the next, so history grows without resizing arrays.

Stack — Undo Last Action

The last entry or exit sits on top of a stack, ready to be popped and reversed.

About This Project

Core Java + Data Structures & Algorithms, presented for demonstration.

Project Summary

The Smart Parking Management System is a Core Java application that automates vehicle entry and exit, allocates the nearest available slot, searches vehicles instantly, calculates fees by duration, and stores every record locally through Java File Handling — no database required.

Technology Stack

Core Java Queue HashMap LinkedList Stack Bubble Sort Insertion Sort Merge Sort Linear Search Binary Search File Handling OOP

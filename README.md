# Java_using_dsa
🚗 Smart Parking Management System

A Smart Parking Management System developed as part of the Summer Internship Training (June–July 2026) on Mastering Data Structures using Java Concepts to Real-world Applications. This project demonstrates the practical implementation of Data Structures and Algorithms (DSA) through a modern web-based parking management application. It provides an efficient solution for managing parking operations, reducing manual effort, and improving vehicle tracking and parking slot utilization. The accompanying project report documents the complete software development lifecycle, including requirement analysis, system design, DSA implementation, testing, and future enhancements.

✨ Features
Interactive Dashboard with real-time parking statistics
Vehicle Entry & Exit Management
Automatic Parking Slot Allocation
Instant Vehicle Search
Parking History Management
Revenue Analytics Dashboard
Report Generation (PDF/CSV)
DSA Visualization (Queue, HashMap, LinkedList & Stack)
Responsive and user-friendly interface

🧠 Data Structures & Algorithms
Queue (FIFO Parking Slot Allocation)
HashMap (Fast Vehicle Search)
LinkedList (Parking History)
Stack (Undo Operations)
Linear & Binary Search
Bubble Sort & Merge Sort
